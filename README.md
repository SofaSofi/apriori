# Apriori: Поиск частых наборов объектов

## Описание
Программа реализует алгоритм Apriori для поиска частых наборов объектов в транзакционных данных (задача анализа рыночной корзины).

## Возможности
- Поиск частых наборов с настраиваемым порогом поддержки
- Два способа сортировки результатов: по убыванию поддержки или лексикографически
- Автоматическое проведение экспериментов с разными порогами поддержки
- Визуализация результатов: время выполнения и распределение наборов по длине

## Файлы
- `apriori.py` — исходный код программы
- `baskets.csv` — набор данных (транзакции супермаркета)
- `experiment_results.csv` — результаты экспериментов
- `time_vs_support.png` — график зависимости времени от порога
- `itemsets_by_length.png` — график количества наборов разной длины

## Запуск
```bash
python apriori.py
