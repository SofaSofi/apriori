# Apriori: Поиск частых наборов и ассоциативных правил

Реализация алгоритма Apriori для анализа рыночной корзины (market basket analysis).

## Структура репозитория

### Исходный код
- `apriori.py` — поиск ассоциативных правил (Практика 2)

### Данные
- `baskets.csv` — набор данных о покупках в супермаркете (7501 транзакция)

### Результаты экспериментов
- `rules_experiment_results.csv` — результаты Практики 2 (время и количество правил)
- `all_rules_30.csv` — список ассоциативных правил при уверенности 30%

### Визуализация
- `rules_time_vs_confidence.png` — время поиска правил при разных порогах уверенности
- `rules_count_vs_confidence.png` — количество найденных правил

### Отчет
- `Отчет_1.pdf` — отчет о выполнении задания
